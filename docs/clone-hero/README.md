# The Clone Hero reference

This folder is the one home of what the project knows about how Clone Hero works.
It describes build 1.1 (v1.1.0.6142) unless a page says otherwise; the fills page also covers 1.0 (v1.0.0.4045).
Last write-back: 2026-10-30 (skeleton; the pages are being written).

## When to read it

Read this page before any Clone Hero question, and before any plan, test or probe that touches the game.

## The four labels

Every rule carries exactly one label. The labels are defined on this page once the writers fill it.

- Proven in the game's code
- Proven in a live run
- Hydra assumes it, never checked
- Unknown

## The pages

- `01-reading-a-chart.md`: finding and reading a chart file, the song id, tracks, song.ini keys, sections, solos and the song end.
- `02-note-list.md`: how the game turns chart notes into the note list it scores.
- `03-timing.md`: Offset and delay, the song clock, the hit window, calibration and playback speed.
- `04-fills.md`: written fills, generated fills in 1.1 and 1.0, and their deadlines.
- `05-star-power.md`: phrases, the meter, activation, drain and the Star Power end.
- `06-scoring.md`: note values, multiplier, accents and ghosts, solo bonus, stars and the score breakdown.
- `07-internals.md`: the game's classes and fields, the per-note hooks, the bot and the two builds' naming.
- `questions.md`: every open split between the game and Hydra that has no ruling yet.
- `live-checks.md`: the rows only a live run can settle.
- `code/README.md`: the index of every annotated listing, and the facts tables.
