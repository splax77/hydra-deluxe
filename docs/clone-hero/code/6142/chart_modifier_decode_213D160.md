# chart_modifier_decode_213D160 (build 6142, RVA `0x213D160`, class #8615)

Made 2026-10-30 with tools/ch_mcp/chdis.py. It turns an N value that is not a pad into a pair (modifier kind, lane), returned in one 8-byte ValueTuple (kind first). The jump table that follows the code (RVA 0x213D29C) was cut off the listing; the cases are in the listing's own immediates.

Lines 1-10: set up. Lines 11-12: values up to 6 go to line 68. Lines 13-21: values 0x22 to 0x2C (34 to 44) go through a jump table. Lines 22-36: N 34, 35, 36, 37, 38 give kind 9 (Accent) on lanes 0xE, 0xF, 0x10, 0x12, 0x11 (Red, Yellow, Blue, Orange, Green drum). Lines 37-51: N 40, 41, 42, 43, 44 give kind 10 (Ghost) on the same five lanes. N 39 is in the table's range but has no case (it falls to line 78, kind 0). Lines 52-67: values outside 34 to 44 are tested for 0x42, 0x43, 0x44 (66, 67, 68): kind 7 (Cymbal) on lanes 0xF (Yellow), 0x10 (Blue), 0x12 (Orange); any other value goes to line 78. Lines 68-77: values up to 6: N 5 gives kind 4 (Flip) and N 6 kind 5 (Tap) on lane 0; the other small values go to line 78. These two are reached only for tracks that did not already take the value as a pad (on drums N 5 is a pad, so only N 6 reaches here). Lines 78-88: kind 0, lane 0 for everything else, then build the tuple with 0x180CE1580 and return it.
