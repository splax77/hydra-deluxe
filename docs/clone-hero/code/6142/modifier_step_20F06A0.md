# modifier_step_20F06A0.asm
The modifier step the note builder calls for modifier bit 8 (NL-68). Lines 32 to 71 walk the note list. A note whose +0x40 tick equals the last kept note's tick, past the first note, has its list slot set to null (lines 41 to 52). Every other note has its +0x80 lane word set to 1 (lines 53 to 55; the kick on drums, NL-50), its tick remembered (line 56) and its +0x18 and +0x10 links cleared (lines 57 to 68). Line 113 then calls RemoveAll with a cached predicate (lines 72 to 102); the predicate's body was not listed. Page 2's NL-69 cites this listing.
