# srb_cipher_managed_32AA80 (build 6142, RVA 0x32AA80)
The managed copy of the block cipher that `srb_cipher_rounds_336E50` falls back to. It makes no calls. Its shape is a table-driven AES encryption of one 16-byte block.
Lines 12 to 21 read the input as four 32-bit words at +0, +4, +8 and +0xC and xor each with the first round-key words. Lines 24 to 283 are a loop whose counter starts at 1 (line 13), steps by 2 (line 269) and runs while it is below 9 (lines 282 and 283), so it passes four times. Each pass does table lookups through one 1 KB table (the fourth argument, `r9`) with byte rotations and round-key xors. Lines 285 to 402 do one more round of the same kind. Lines 403 to 491 do a final round from byte lookups in a second table, with no rotation through the big table, and write four words to the output (line 491 writes the last).
Counted that way, the cipher runs ten rounds on a 16-byte block, which is AES-128 encryption. That each loop pass is two rounds is read from the counter step and the two lookup groups (lines 24 to 147 and 148 to 281), not from a run.
