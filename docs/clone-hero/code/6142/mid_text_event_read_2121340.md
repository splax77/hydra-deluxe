# mid_text_event_read_2121340 (build 6142, RVA `0x2121340`, class #8537)

Made 2026-11-08 with tools/ch_mcp/chdis.py (`py -m tools.ch_mcp.chdis 2121340 200`). It is the read method of the base class of every MIDI text-like meta event (dump.cs line 543325, TypeDefIndex 8537). That class has one field, the event's text string at +0x20 (dump.cs line 543328). The text event the drum reader tests (`mid_drum_reader_2155050.asm` lines 356 to 363, class #8623 at dump.cs line 550220) derives from this class and does not override this method: the method is `sealed override` in the base (dump.cs line 543333).

Lines 1 to 30: set up, with the strings `Text event cannot be read since the size is negative number.` and `size` (lines 24 and 26). Lines 31 to 53: a negative size throws (line 53). Lines 54 to 94: read the event's bytes into a span and fetch a static Encoding object (lines 75 to 82). Lines 95 and 96: `Encoding.GetString` on those bytes, stored straight into +0x20. Lines 99 to 102: the other branch stores the string class's static empty string instead (which branch a zero-length event takes was not traced). Lines 103 to 112: write barrier and return. No call between the byte read and the store trims, changes case or otherwise edits the text.
