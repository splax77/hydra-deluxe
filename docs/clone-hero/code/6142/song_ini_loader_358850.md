# song_ini_loader_358850 (build 6142, RVA 0x358850), SongEntry (TypeDefIndex 176)
Despite the name the record gave it, this is the song.ini writer, not the reader. It checks each metadata key with 0x1803579B0 and, for a missing one, formats a line such as "song_length = {0}" (line 88), "delay = {0}" (lines 319 to 345) or "video_start_time = {0}", adds it to a list of lines and logs "Creating metadata file for". The key list (name, artist, album, genre, year, charter, icon, the diff_* keys, preview_start_time, video_start_time, delay, song_length, playlist_track, album_track, pro_drums, five_lane_drums, modchart, explicit_lyrics) was found by scanning the function for loads of each key literal. Line 674 loads "song.ini". The listing is 1438 lines; only the lines named above (88, 319 to 345 and 674) were read in detail.
