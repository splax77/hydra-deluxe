# midi_header_read_211AF60.asm
The reader of a MIDI file's MThd header chunk, class TypeDefIndex 8529 (dump.cs line 541967; the class names the chunk "MThd"). The header holds three big-endian 16-bit words in the order format, track count, time division. Lines 25 to 34 read the first word and byte-swap it, line 61 checks it against an enum, and line 66 stores it at +0x10. Lines 69 to 80 read the second word into +0x14. Line 82 reads the third with a signed 16-bit read; line 84 sends a negative value (SMPTE timing) to a NotSupportedException, and line 86 stores the rest at +0x12. So +0x12 holds the file's ticks per quarter note. Page 2's NL-58 cites this listing.
