# pitch_difficulty_map_210D9C0 (build 6142, RVA `0x210D9C0`)

Made 2026-10-30 with tools/ch_mcp/chdis.py. It maps a .mid note pitch to a difficulty byte. Lines 1-3 and 24-25: pitches 58 to 66 (pitch minus 0x3A up to 8) return 0 (Easy). Lines 4-6 and 22-23: 70 to 78 return 1 (Medium). Lines 7-9 and 20-21: 82 to 90 return 2 (Hard). Lines 10-16: 94 to 102 return 3 (Expert); anything else returns 0xFF (skip the note).

Side reading, not a separate listing: the type map `0x210D7B0` (committed copy docs/audit/note-shuffle/step0/open2/f210d7b0.asm) subtracts 59, rejects above 42, looks the result up in a byte table at RVA `0x210D824` and then in a jump table at RVA `0x210D808`. Decoded today: pitches 59 and 60 are type 13 (KickDrum), 61 type 14 (Red), 62 type 15 (Yellow), 63 type 16 (Blue), 64 type 18 (Orange), 65 type 17 (Green); 66 to 70 and 58 are type 0 (skipped); the same block repeats at +12, +24 and +36. The helper `0x210D780` returns true for pitches 65, 77, 89 and 101 (the Green pad of each difficulty).
