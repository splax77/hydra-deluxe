# mid_drum_reader_2155050 (build 6142, RVA `0x2155050`, class #8626)

Made 2026-10-30 with tools/ch_mcp/chdis.py. It reads one MIDI drum track. Inputs: the track's event list (rcx), the chart-info object (rdx; its first field is the chart being filled) and the instrument byte (r8, 6 = Drums when called from `0x2155C00`). The 8-entry jump table at RVA 0x2155B2C follows the code and was cut off the listing; it is decoded below. The listing is annotated at the two points the brief names: the dynamics tag at lines 420-433 (0x21557A5 at line 422) and the 2x kick test at lines 316-324 (0x21555CD at line 316).

Lines 1-61: set up and first-call metadata slots (the strings `[ENABLE_CHART_DYNAMICS]`, `mix`, `ENABLE_CHART_DYNAMICS`, `[mix`). Lines 62-76: clear locals. Lines 77-79: call `0x21581E0` (it returns a static ThreadLocal bool of this class); true jumps to line 562, which calls `0x2154180` instead of reading the drum track. Lines 80-101: take the chart object and its first two bytes (+0x10, +0x11) as the starting values of two local flags, get the track for difficulty 3 (Expert) with 0x20CFD40, and set the local dynamics byte `[rsp+0x41]` to 0 (the 0x215524D store at line 100). Lines 102-123: start walking the event list in its order.

Lines 124-140: for a note event (the type test at 125-129), read its start tick and its end (note-off), and, when the second local flag is still 0, call `0x210D780` (true for pitches 65, 77, 89, 101) to set the first local flag. Lines 148-154: length = off minus on. Lines 151-243: a pitch above 116 or in the marker set is a marker: 120 calls 0x20CEDC0 (lines 155-164); 126 and 127 compute a difficulty number from the velocity (lines 165-224) and call 0x20CEEC0; 103 calls 0x20CF1B0 (lines 225-234); pitches 109 to 116 go through the jump table at RVA 0x2155B2C (lines 235-243): 109 to line 244 (a Flam record, kind 8, lane 255, added with 0x20CFBC0), 110 to 112 to line 270 (set the second local flag, make a Tom record, kind 6, with lane 15, 16 or 18; lines 270-294), 113 to 115 to line 303 (the plain note path), 116 to line 295 (0x20CF0B0 with the length, the Star Power phrase). Line 270 `mov byte ptr [rsp+0x42], 1` is the "pro drums" byte.

Lines 303-315 (a plain note): get the difficulty from the pitch with `0x210D9C0` (0xFF skips), then the type from `0x210D7B0` (0 skips). Lines 316-324: the 2x kick test: cl = pitch minus 59; when cl is 36 or less and bit cl of 0x1001001001 is set (pitches 59, 71, 83, 95), flags = 8 (DoubleKick), else 0. Lines 325-333: when the local dynamics byte is set, velocity 1 sets bit 9 (Ghost 0x200) and velocity 127 sets bit 10 (Accent 0x400). Lines 334-340: type 14 (Red) adds flag 0x10 (Tom); type 13 (Kick) adds nothing; any other type adds 0x20 (Cymbal). Lines 341-354: get the track for the note's difficulty (0x20CFD40) and add the note with 0x20CEC60 (tick, type, length, flags). Line 355 continues with the text-event test below for the same event.

Lines 355-362: is the event a text event (the class check at 356-358 and the text at +0x20)? Lines 363-375: does the raw text start with `[mix` or `mix` (String.StartsWith, no trim)? No goes to line 419. Lines 376-405: call the mix parser `0x215C750` on it; false goes to line 419. Lines 406-418: get the track for the parsed difficulty and add the mix event with 0x213B130. Lines 419-433: test the text for equality with `ENABLE_CHART_DYNAMICS` (line 422, 0x21557A5) and then `[ENABLE_CHART_DYNAMICS]` (line 428, 0x21557BB); either one sets the local dynamics byte (line 432, 0x21557CD). Line 433 goes back to the loop at line 115.

Lines 434-436: the loop ended. Lines 437-570: for each track filled, copy solos, phrases, lanes and fills from the Expert-track object into the other difficulties' tracks (lines 456-540), set each track's flags +0xA1 and +0xA2 from the two local flags (lines 552-556), and call the track finish `0x215C320` (line 557). Lines 571-581: return. Lines 582-619: error stubs; the text `Invalid tom marker note number` (line 592) is thrown from line 587 when a tom marker's pitch is not 110, 111 or 112.
