# mix_parser_215C750 (build 6142, RVA `0x215C750`, class #8661)

Made 2026-10-30 with tools/ch_mcp/chdis.py. It reads the text of one mix event and returns (difficulty byte, the text from `drums` on, tick) with a true or false result. Inputs: the text span (rcx), the tick (rdx), where to put the tuple (r8).

Lines 1-55: set up and first-call loading of the metadata slots (IndexOf, SequenceEqual, StartsWith, the strings `mix` and `drums`). Line 59: trim whitespace off both ends. Lines 60-84: if the text is not empty and starts with `[`, drop it; and if the last character is `]`, drop that too (when the closing bracket is missing the text simply loses only the first `[`). Lines 85-100: make a scratch buffer of that many characters. Lines 158-174 (reached from line 105): copy the characters into it, turning each `_` (0x5F) into a space (0x20). Lines 101-115: wrap the buffer as a span. Lines 116-128: find the first space; none means return false (line 128 jumps to the false exit). Lines 140-184: compare the text before that space with `mix` (SequenceEqual, exact); different returns false. Lines 185-204: take what follows the space and trim leading whitespace. Lines 205-214: find the next space in it; none returns false. Lines 215-235: call Int32.TryParse on the text before that space; failure returns false. Lines 236-248: map the number with `0x210D990` and return false when it gives 0xFF. Lines 249-263: take what follows and trim leading whitespace. Lines 265-290: test that it starts with `drums` (ordinal); no returns false. Lines 291-313: turn the rest into a string, build the tuple (difficulty, that string, the tick) with the ValueTuple constructor, and return true. Lines 314-330: the false exit (`xor eax, eax`) and the throw stubs.
