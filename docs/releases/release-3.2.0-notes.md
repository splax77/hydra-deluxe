Hydra Deluxe 3.2.0 makes `1.0 fills` follow Clone Hero 1.0's own fill rules: where a generated fill sits, and when its deadline ends. It also picks the activation note the way Clone Hero does when a chord mixes cymbals and toms, and rates a squeezed-out note past the SP end like any other note there. Your saved results read `Stale` once: every result saved by 3.1.2 or earlier is marked `Stale` until you open the song or run `Analyze library...`. No scan starts, and your library and settings carry over.

**Update from the app.** If you run 2.12.0 or later, the bar at the top of the window offers this release the next time Hydra Deluxe starts; click `Update`. If you run 2.11.0 or 2.11.1 with its update check on, a line under the toolbar offers it once its daily check runs. From 2.10.2 or earlier, download the `-setup.exe` file below and run it.

**`1.0 fills` places fills where Clone Hero 1.0 does.** On a chart with no fills of its own, Clone Hero makes the fills itself, and 1.0 does it by a different rule from 1.1. With `1.0 fills` checked, Hydra Deluxe now follows 1.0's rule. A chord gets a fill only if it sits within 0.25 seconds of one of 1.0's measure lines. The fill starts halfway between the measure line before and that one, so it can be longer or shorter than half a measure. So with `1.0 fills` checked, the Preview can show fills on other measure lines than before, and a song can get a different best path. With `1.0 fills` off, fills are placed as before.

**The 1.0 fill deadline ends a 64th note past the chord.** Under `1.0 fills`, your Star Power has to be ready by a fill's deadline for the fill to appear. That deadline now ends a 64th note past the fill's chord, timed at the song's tempo there, and it still stays between 250 ms and 10 seconds. This can change which fills a path gets under `1.0 fills`.

**The activation note ranks cymbals above toms.** On a chord with more than one pad, one note is the activation note: on a frontend squeeze, it's the note you hit first. Hydra Deluxe used to pick green, then blue, then yellow, then red, whether a note was a cymbal or a tom. It now ranks the way Clone Hero does: any cymbal comes before any tom, green before blue before yellow within each, then red, and the kick only on a chord with no pad. So a yellow cymbal played with a green tom is now the activation note, where before the green tom was. The Preview marks the new note.

**A squeezed-out note past the SP end reads like any note there.** In the Paths tab's `Backend timings`, the note a path squeezes out used to always show the late hit its squeeze-out needs. Inside Star Power it still does. Past the SP end, it now reads like any other note that far past the end: `Normal` within the backend leeway, otherwise the early hit by its `Timing`, tagged `(uncounted)`. So a squeezed-out note 50 ms past the end reads `Extreme (uncounted) <-- squeezed out`.

**The Preview's Star Power gauge on an early squeeze-out.** When a path squeezes out a note inside Star Power, Star Power ends on that note, before the plain SP end. The gauge in the Preview now stops there and drops what's left in it, where it used to drain to empty at the plain SP end. An SP phrase that is squeezed out is added to the gauge on the squeezed note itself.

**The Paths tab's two folds are headings.** `Multiplier squeeze` and `Score breakdown`, under the activation rows, are now headings with an arrow. Click the arrow or the name to open or close one. The points the multiplier squeezes add sit beside the name, like `Multiplier squeeze · +15`. A song with none shows `Multiplier squeeze · none` in gray, with no arrow. `Copy path` now sits on its own line under the folds.

**Smaller changes.**
- The Preview's `Showing` list names the all-0 path `Best all-0 path`, as the Paths tab does: `0 0 0 0  (Best all-0 path)`.
- During `Analyze library...`, the time left under the toolbar comes from the charts done since the batch started, over the time it has run, leaving out any time it was paused. It shows once the batch has finished two charts for each analysis worker.
- The player list in `Compare` is sorted A to Z, ignoring case and accents, as the library search does.
- The `Dynamic Hit Window:` tag (`safe` or `short`) on a squeeze box is now drawn the same size as the other badges, in the same colours.
- In `hydra_rules.ini`, the `fill_cooldown_measures` line is gone, because both Clone Hero versions wait a fixed 4 measure lines after a fill. A file that still has the line keeps working: Hydra Deluxe reads it and ignores it.
