Hydra Deluxe 2.4.0 adds Clone Hero 1.1's Note Shuffle modifier. The path report and the dmleaderboards comparison now open in Hydra's own windows, and the analysis settings sit behind one toolbar button. Hydra also reads a 2x kick and a normal kick on the same tick the way Clone Hero does.

**Every saved result reads Stale.** The kick change can change a chart's notes, so this release marks every saved result out of date. A song's Best path cell reads `Stale` until it is analyzed again. Open a song to refresh it, or run a batch. A batch re-runs Stale songs without `Also re-analyze charts that already have a result` ticked.

**.sng and .srb songs start over.** Hydra now gives a .sng or .srb chart Clone Hero's own song id, as it already did for chart folders. Results saved for those songs no longer match a chart, so the first scan removes them and those songs read `Not analyzed`. Open them or run a batch to analyze them again. That first scan also reads every chart once, so it takes longer than usual. In return, the dmleaderboards comparison can now find .sng and .srb songs. A .sng and a folder holding the same notes now show as one chart with two copies. A .sng with no notes file inside, or an .srb cut short before its id, is now listed as a scan error instead of a song that fails when you click it.

**Note Shuffle.** A new `Note Shuffle` checkbox in the settings panel, off by default, scores the chart the way Clone Hero 1.1's Note Shuffle modifier rearranges it. The game's rearrangement is the same every time for a given chart and drum setting. The Paths, Preview, Stars and Dynamics tabs and batches all follow the checkbox. Shuffled results are saved beside the normal ones, so turning it off brings your normal results straight back. `Compare with dmleaderboards...` is greyed out while it is on, because dmleaderboards scores don't say whether Note Shuffle was on. A chart that Clone Hero freezes on with Note Shuffle on gets no path, and Hydra says "Clone Hero freezes loading this chart with Note Shuffle on."

**A 2x kick and a normal kick on one tick become one 2x kick, as in Clone Hero.** With 2x Bass off, the game then removes that kick, so the tick has no kick. Hydra used to keep the normal kick and score a kick the game doesn't have. Among Hydra's own test charts, none of the 55 with 2x kicks has a tick like that. A note marked both ghost and accent now plays as an accent, as in the game. Total scores don't change, since ghosts and accents score the same. Only the label changes, so in the Score breakdown such a note's points can move from `Ghost Notes` to `Accent Notes`.

**Reports open inside Hydra.** The path report and the dmleaderboards comparison now open in their own Hydra windows instead of a web page. Each has its own taskbar button, can sit on another monitor, and opens where you last left it. Click a column heading to sort, click it again to flip the order, and Shift+click another heading to add a second sort. Click a row to select that song in Hydra. Hydra no longer writes `hydra_paths.html` or `hydra_dmcompare.html`, and it leaves old copies in your Documents\Hydra folder for you to delete. `Show in folder` and the `hydra_report` tool are gone, and there is no export. Screen readers can't read these windows.

**Closing the path report frees its memory.** Closing the window lets the report go, and a build still running stops. Opening it again builds a fresh one and keeps your search, timing, `Best path only` and sort.

**One button for the analysis settings.** The settings bar is now one toolbar button, `Analysis settings`. Its label names only the settings you changed from the defaults, or reads `defaults`. Click it to open a panel with every analysis setting; changes apply as you make them. `Reset to defaults` puts all eight back in one step, so the open song re-analyzes once. It leaves your song folders alone. While a batch runs, the settings are locked.

**The Preview keeps its place.** Changing the difficulty, Pro Drums, 2x Bass or Note Shuffle swaps the notes in place. The song keeps playing, or stays paused, at the same spot instead of going back to the start.

**Smaller changes.** The song panel no longer jumps while a setting change re-analyzes the open song. On the Paths tab, the backend tables, `Multiplier squeeze` and `Score breakdown` start open. The comparison's first tile reads `Scores shown` and counts the rows your filters show.
