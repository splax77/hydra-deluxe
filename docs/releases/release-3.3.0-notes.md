Hydra Deluxe 3.3.0 adds a `Song speed` setting, so you can price a chart at the speed you play it in Clone Hero, and a `Safe paths` setting that keeps only paths whose every `Dynamic Hit Window:` row reads `safe`. Both report windows can now export their table to Excel. Your saved results carry over as they are: each one is filed under 100% speed with `Safe paths` off, which are the defaults, so nothing reads `Stale` and no scan starts.

**Update from the app.** If you run 2.12.0 or later, the bar at the top of the window offers this release the next time Hydra Deluxe starts; click `Update`. If you run 2.11.0 or 2.11.1 with its update check on, a line under the toolbar offers it once its daily check runs. From 2.10.2 or earlier, download the `-setup.exe` file below and run it.

**`Song speed` analyzes the chart at your Clone Hero speed.** The new box sits under `Clone Hero rules` in `Analysis settings`. It takes a percent from 10% to 5000%, Clone Hero's own limits, and starts at 100%, the chart's own speed. Clone Hero plays every note sooner or later by the speed, but each note's hit window stays the same size in real time, and Hydra Deluxe follows the same rule. So every squeeze and timing figure, every time on the Paths tab, the Preview and the Path Builder, and the song's length are in played time at that speed. At 200% a squeeze needs half the milliseconds it needs at 100%. The `Rating` words and the path report's timing tiers stay in steps of 85 ms at every speed, so a faster speed can make a squeeze easier. Star Power lasts the same number of beats at every speed, and so does Clone Hero 1.1's 4-beat fill deadline. The `Dynamic Hit Window:` row's windows narrow at faster speeds, because the game sizes them from the real-time gaps between notes.

**The Preview plays at the song speed.** The audio is time-stretched, so its pitch stays the same. When you change the speed, the Preview keeps its place in the song.

**Results are kept per speed.** A 100% result and a 150% result for the same song sit side by side, and the path report and a library analysis use the speed you set. The `Analyze library` window lists `Song speed` with the other settings it will use. The dmleaderboards comparison always reads your 100% results, whatever `Song speed` says. Its footer now tells you what to do about charts with no current result: `Reset to defaults, analyze them, then compare again.`

**`Safe paths` keeps only paths the game's windows can reach.** The new checkbox sits under `Paths kept` and is off by default. When you check it, Hydra Deluxe drops every path that holds a squeeze or early fill whose `Dynamic Hit Window:` row reads short. It drops the best path too, so the paths you see are the best ones whose every row reads `safe`. It is separate from `Path limit`: neither setting reads the other, and a path that ties the best score gets no exception. The Path Builder ignores it. Results are kept per setting, and the `Analyze library` window lists it too.

**Both reports export to Excel.** The path report and the dmleaderboards comparison each have an `Export to Excel...` button beside `Refresh`. It saves the table as the window shows it, in the window's own colours, to an `.xlsx` file. The save box suggests a name like `Path report 2026-11-24.xlsx` or `dmleaderboards <player> 2026-11-24.xlsx`, and opens in the folder you last exported to.

**The comparison shows `Timing required`.** In the dmleaderboards comparison, the `% of opt` column is gone. In its place, `Timing required` shows the hardest squeeze or required early fill your optimal path needs, in ms, the same figure as the path report's `Hardest ms`. It shows for scores at any speed, and a dash means the path needs none or Hydra Deluxe has no result for the chart. The `Avg % of optimal` tile is gone with the column.

**The `safe` or `short` tag sits under its badge.** On the Paths tab, each `Dynamic Hit Window:` tag, like `5.4 ms safe`, now shows directly under its squeeze or early fill badge on the activation's line, instead of inside the opened box. It shows while the activation's row is open.

**85 ms is the timing step.** The fixed 85 ms that sets the `Rating` words and the path report's timing tiers is not Clone Hero's hit window, which the game works out for each note. The path report's `Timing` tooltip and footer and the `Early fill window` help now say "steps of 85 ms" and no longer call it the hit window. Nothing about the figures changes.

**Smaller fixes.** A click in the Path Builder no longer makes the screen flicker. Reading your library waits up to 2 seconds for a lock on `hydra.db` instead of failing at once with `database is locked`.
