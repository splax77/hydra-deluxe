Hydra Deluxe 3.1.0 changes how the Preview tab's highway shows where Star Power runs out. The railings now mark it, so nothing on the lanes can be mistaken for a kick. Your saved results carry over as they are from 3.0.0 or later: nothing reads `Stale` and nothing is analyzed again. If you update from 2.14.0 or earlier, the 3.0.0 notes apply: your results read `Stale` once.

**Update from the app.** If you run 2.12.0 or later, the bar at the top of the window offers this release the next time Hydra Deluxe starts; click `Update`. If you run 2.11.0 or 2.11.1 with its update check on, a line under the toolbar offers it once its daily check runs. From 2.10.2 or earlier, download the `-setup.exe` file below and run it.

**The railings show where Star Power runs.** Both railings are teal while Star Power is running and grey everywhere else. The point where they turn grey is exactly where Star Power stops, and the teal floor ends at the same point. The railings sit outside the lanes, so a note never covers them, even when Star Power ends on a note. A solo doesn't change the railings.

**The magenta mark is gone.** In 3.0.2, a magenta line crossed all four lanes where Star Power ended, with a small magenta triangle outside each railing. Star Power often ends on a kick, so the line was easy to read as one. Both the line and the triangles are removed.

**The teal floor is brighter.** Inside a Star Power window the floor is a clearer teal than before, so its far edge reads as a second line at the end. The `SP drain` box keeps its colour.
