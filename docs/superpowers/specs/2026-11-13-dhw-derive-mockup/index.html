Mockup. The Dynamic Hit Window row on seven real activations, as the plan would draw it.
Click an activation to open or close it. "Collapse all" closes every one in its panel. Each opened activation shows its sentence (today's text, unchanged), the new row under it, and a grey line with the row Hydra 3.0.0 draws today. The new row is the label, then the frontend end, then the backend end, then the tag at the right edge. Each end is the word, that note's window, then that note's chord. An early fill has one end. The tag reads "xx ms safe" at 0.0 or more and "xx ms short" below 0, and its value is the same sum Hydra 3.0.0 draws, with "spare" renamed "safe". Not real here: the points figure in a squeeze-out sentence is left as "…" because the figures file does not hold it. Chord words are written as Hydra prints them with Pro Drums on, as on the user's screen, and assume a plain (not 2x) kick.
