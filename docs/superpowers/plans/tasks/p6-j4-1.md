**`settings_key(const SearchSettings&)`** goes into `pather.h`/`.cpp`: it returns the text `add_settings` writes today, in the same field order with the same `|` separators and the same "none" for an unset ms filter, so the cache key's shape does not change. **The temp path.** `temp_ini` goes; `load_ini_text` and the "a missing INI yields defaults" case call J4-6's helper with the tag and `.ini`.
