## Goal

The track state is the timeline the Preview highway draws from: one instant per moment anything happens, carrying what every span (SP phrase, solo, fill, taken fill, active SP window, lit lane) does at that moment. Five questions about it are answered twice inside `track_state.cpp` and its tests. After this task each has one owner inside `track_state`, and the header exports the four small facts the draw code and the tests need. No score, path, record, pixel or label changes; the golden image and the random and corpus equality tests must pass untouched.

## What changes

**One span rule.** `SpanSweep` moves into `track_state.h` (its class as it is, with its "ask in increasing order" note). `synthesize` builds one sweep per span field and asks it once at t. `toggle_at` is deleted from the header and the file (D54); the header comments at lines 137 to 139 and 167 to 170 that call it "the reference rule" are rewritten to name the sweep. The truth-table test asks `SpanSweep`.

**One lane tie-break.** `synthesize`'s two hand scans go; it builds a `LaneSweep` over `fill_lane_ivs_` and asks it once. `LaneSweep` can stay file-private. Then the owner for D53 item 3: a lane-span builder beside `make_toggle_bounds`, say `make_lane_bounds(win, near, far)`, which returns the lit-lane stretches of the window with each stretch carrying its pad. It merges neighbours only while the pad is the same, so a change of pad at an instant ends one stretch and starts the next; a stretch entering the window takes the pad in force before the first instant (when that instant is a Restart, the pad comes from the instant before the window, which `TrackWindow`'s view into the state can reach). The per-instant `fill_lane_pad` stays, because `highway_draw.cpp` reads it until J2-8 switches the draw code to the new builder. With one fill the stretches equal `make_toggle_bounds` on `fill_lane`.

**One overlay merge.** `build_track_state` builds the path-free instants (notes, beats, SP phrase and solo edges) with their `base_t_`, then calls the same merge `rebuild_overlay_fields` uses to add the overlay's edges and sweep the fields. The four-name overlay list is typed once. The pinned timelines and the two equality tests prove the instants are the same.

**`toggle_on_after(Toggle)`** is exported from `track_state.h` beside the enum (see the plan correction for the name) and `make_toggle_bounds` line 442 calls it. Line 429 keeps its own three-way test, since it asks "on before". `highway_draw.cpp`'s private copy stays until J2-8.

**`TrackStateOptions::operator==`** (and `!=`) in `track_state.h`, over its one field.

**The span check and `kSpanEndTicks`** are exported from `track_state.h`: the constant moves there, and a predicate, say `note_in_span(scene, span, note)`, says whether a note is inside a span by the track state's own rule (its time at or after the span's start and no later than the end `span_interval` computes). Export `span_interval` too if the predicate reads better built on the exported form. The golden dump's two hand compares call the predicate (add the `render/track_state.h` include). The dump is a dev aid behind `HYDRA_PREVIEW_DUMP`, so this is code-only.

**The renderer test** calls `render::track_height(r.config(), 100, 300)` in both places it typed 117.
