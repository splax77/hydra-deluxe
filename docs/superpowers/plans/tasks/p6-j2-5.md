## What changes

**The stars message is built once.** `kStarsError` becomes a string built from `kMaxStars` ("stars: needs a number from 0 to " and the number), so "0 to 7" is typed nowhere in `src`. The tests keep their literal pins of the full sentence; that is a pin from a run, which D42 allows, and it proves the text is unchanged.

**`term_applies_to`.** One function in `library_query.cpp`, `term_applies_to(QueryField term_field, QueryField column)`, answers true when either side is `Any` or the two are equal. `term_matches` becomes "any column the term applies to contains the folded text" over the four columns, and `match_spans` asks the same function for its skip. Export it from `library_query.h` so a test can pin it; the matching rules themselves do not change.

**The four private helpers call strutil.** `is_ascii_space`, `ascii_lower`, `iequals_ascii` and `starts_with_ci` go, and their callers in `library_query.cpp` call J2-1's exports. Byte-for-byte behaviour: the helpers only ever touch ASCII and no locale is set.

**`DynamicsCounts::dynamic()`.** The header gets `int dynamic() const` returning `ghost + accent`; `has_dynamics` reads it, and the tab's "Dynamic notes" line reads it. The tab's other lines (the per-row tables, the "Ghosts" and "Accents" counts) are unchanged.

**The Dynamics blob uses serialize's codec.** `encode_dynamics` fills a `BinaryWriter` (`u8` for the stamp and the enabled flag, `u32` for every count, the late tag and the marks) and returns its bytes; `decode_dynamics` keeps its two early returns (too short, wrong stamp) and then reads through a `BinaryReader`. `write_u32_le` and `read_u32_le` are deleted. The bytes must be identical: pin them from one run before you touch the codec (case 4 below).

**The Preview asks `chart_format_of` once per function.** `is_container_path`, `resolve_preview_song` and `resolve_preview_stems` each call `chart_format_of(notespath)` once and switch on the answer (`Sng`, `Srb`, anything else), so `ends_with_ci(..., ".sng")` and `".srb"` appear nowhere outside `chart_files.cpp`.

**The Preview's four private copies go.** The private `find_song_ini` is deleted; `resolve_preview_song` calls `hydra::find_song_ini(parent_folder(notespath))`. `dir_name` is deleted; its three callers call `parent_folder`. `find_loose_audio`'s bare join calls `join_folder`. `srb_audio_from` wraps the buffer with `memory_byte_source`, calls `srb_read_metadata` for the first offset, and inflates the notes stream from there as it does today; keep the early return for a buffer no longer than the header and the catch that ends the walk on a malformed stream.

**`test_preview_source.cpp` builds through `sng_util.h`.** Its `push_u32`, `push_u64`, `SngFile` and `make_sng` go; every call becomes `testsng::make_sng(pairs, files)` with the arguments reordered (metadata first, then name-and-bytes pairs). Fixtures that passed no pairs now carry an empty metadata block instead of 20 junk bytes; the loader reads both as "no metadata", so no case's result changes. `write_bytes`, `fixture_dir` and the .srb helpers in that file stay.
