## Goal

The library scan stops answering five questions itself and asks the owners J1-5 built: which notes file wins, which file is the folder's song.ini, where an .srb's metadata stream is, what a path's parent folder is, and how a test builds a .sng. It also becomes the owner of three facts other code copies: how a scan row becomes a library entry, how many workers a batch gets, and how a chart hash is spelled. The scan's output is byte-identical before and after; the checked-in scan snapshot proves it.

This is the only wave in which `src/app/analysis.cpp` and `analysis.h` can be edited (phase 7 holds them in its waves 2 and 3). So leave no `analysis.cpp` caller for a later task. Every repoint this brief names lands here.

## What changes

**The scan calls J1-5's owners.** `discover_charts` hands the notes-file names it listed to `pick_notes_file` and the folder's entries to `find_song_ini`, and keeps the `DirEntry` it needs for the signature. It already has the folder's listing from `list_dir`, so it must not list the folder a second time: if J1-5's `find_song_ini` only takes a folder path and walks it itself, stop and report (the scan walks thousands of folders, and `chart_files.cpp` is not yours). `parse_srb_metadata` wraps the captured head bytes with `memory_byte_source` and calls J1-5's .srb reader; its empty-on-failure behaviour stays. `parent_of` is deleted and `rootfolder` comes from `parent_folder`. Before you switch it, compare J1-5's pinned trailing-separator row with what `parent_of` does (it strips the separator first, so the parent of `C:\a\b\` is `C:\a`). A library root the user typed with a trailing backslash reaches this line as-is. If the two rules differ there, stop and report in game terms: a chart sitting directly in such a root would be filed under a different folder text in the library.

**Three new owners in `analysis.h`/`.cpp`.** `to_library_entry(const ScanItem&)` copies the seven fields by name. `normalize_chart_hash` sits beside `stream_md5` and lowers a hash's ASCII letters; it has no production caller yet (J2-2 adds them) and the commit says so. `batch_worker_count` keeps its rule unchanged (D54).

**`run_work_pool` trusts its count.** Its floor goes. Without the floor a count of 0 would start no workers and leave the consumer waiting forever, so the pool refuses a count below 1 with an error that names it, the file's fail-loudly way. That is not a new limit; it is the existing floor kept in one place (`batch_worker_count`) and checked, not silently repaired, in the other. `set_analyzer_for_test`'s floor is J2-4's (see "Plan corrections").

**The tests read the owners.** The rescan-cache test builds its entries through `to_library_entry`. `write_sng_with_metadata` is deleted and the "(unknown)" test writes the bytes `make_sng` from `tests/sng_util.h` returns (the test's own file-writing stays). The test's metadata now has a real length field; nothing it checks changes.
