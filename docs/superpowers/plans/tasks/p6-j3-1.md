## Decided at launch (D53/D54 addendum)

The user said to use the recommended answer for everything. Nothing here is visible or stored, but these shapes had no decision written down:

- `sqout_cost` is a free inline function in `backend_value.h`, taking the same four facts `backend_row_value` takes, so the cost and the value can never drift apart.
- A missing backend offset fails loudly through one accessor, `BackendSqueeze::offset()`, which throws naming the row's tick. The field stays optional this phase so the codec and the test fixtures do not move; making it non-optional is a later call.
- The lane rule has two exported owners beside `allows_cymbals`: `lane_allows_flag` (may this lane carry a flag) and `set_lane_flag` (what the flag means: 2x on the kick, a cymbal on a pad), with `lane_flag` exported as the reader. The audit asked for one predicate; the test needs the setter too, and one writer of the split is the point.
- `dynamic_label` capitalises `dynamic_str` and gives "" for Normal, so hydra_replay's "none" and `ChordNote::str`'s empty suffix both stay as they are.
- `squeeze_kind_from_name` returns an optional; an unknown word is "no kind", which keeps the JSON reader's skip.
- The six-field sum, `score_total`, lives in `model.h` as an inline free function, not a `Path` method, so `ReplayScore` and the engine can call it without a `Path`.
- 152's model half is closed by E3's `Activation::hardest()`; this task adds no second function.
