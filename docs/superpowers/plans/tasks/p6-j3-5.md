## Decided at launch (D53/D54 addendum)

The user said to use the recommended answer for everything. Nothing here is visible or stored, but these shapes had no decision written down:

- The jump is typed as whole seconds (`kJumpSeconds = 5`) and the milliseconds derived, so the labels print an integer and no number is formatted from a double. The user's decision fixed 5 s, not the spelling.
- `shows_path` compares the path part of the drawn key with the selected key for equality, as D54 says. It differs from today's prefix test only for an empty selected key against a real drawn path (prefix says yes, equality says no); "Show in Preview" never sets a jump without a selected path, so the app cannot reach that input.
- `track_options(bool)` lives in `preview_load_job.h`, not on the controller alone, because the load job builds the first timeline on its worker with no controller in reach. The controller's `track_opts()` calls it.
