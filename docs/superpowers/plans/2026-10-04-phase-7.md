## How it runs

The rules carry over from phases 3 to 5:
- **Who runs what.** Planning agents run on Fable. Code executors run on Opus. Reviewers run on Sonnet. Each wave is one Workflow of parallel executors, each in its own worktree.
- **Tests.** Agents never run the full suite. Each brief names its test files and its `-tc=`/`-sf=` filters; probe tasks run their own pytest files. The main session runs the full suite once per merge to main.
- **No silent stalls.** Every agent writes a status line every 10 calls or 5 minutes. A blocked agent stops and reports the exact error; it never waits. Helpers run in the foreground. Agents commit before 110 calls.
- **Review gate.** Every merge to main needs a CLEAN derive-once review from a fresh Sonnet reviewer first. If merge M0 has landed by then, the precheck script runs before each review. Otherwise the reviewer does that step by hand.
- **Your calls first.** Anything that changes a display or a stored record follows your answer to the questions sheet. Any new number a task needs, and no decision covers, stops the task and comes to you.
- **Briefs.** No code listings in briefs. Each task gets its own brief file, `tasks/p7-<id>.md`, with the shared preamble. I write the briefs once you've answered.
- **Ordering.** A task that needs another task's owner forks from that task's commit, not from its review. Cold builds start at most three at a time.

## What others do

Four of these fixes follow patterns other projects already use.

- **Comments after a value.** inih, a widely used INI parser, makes this exact choice behind a switch (`INI_ALLOW_INLINE_COMMENTS`). Allowing them is its default ([benhoyt/inih](https://github.com/benhoyt/inih)).
- **Typed values that escape a slider.** Dear ImGui offers `ImGuiSliderFlags_AlwaysClamp` so that Ctrl+click typing obeys the slider's range ([imgui.h](https://github.com/ocornut/imgui/blob/master/imgui.h)).
- **A FLAC length of 0.** RFC 9639 says a zero total in STREAMINFO means the length is unknown, not empty ([RFC 9639](https://www.rfc-editor.org/rfc/rfc9639.html)). Counting by decoding once is what players do when the header has no answer.
- **The scan cache's stamp.** It uses the same "stored data carries a version stamp" pattern ADR 0018 already uses for results and dynamics, so nothing new is invented.
