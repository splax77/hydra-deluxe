## 4. Questions for the user

**Q1 (finding 112): the Score range box's width.** Today the box is sized to six zeros, "000000". In the shipped font 8 is the widest digit, so six 8s are about half a pixel wider (times your DPI scale) than six 0s. After the fold the box is sized by `widest_digits(6)`, the same rule the Analyze button and the Preview already use, so it grows by that half pixel. You will not be able to tell; frame padding hides it today. Recommendation: fold it, so a font change can never clip the box.

**Q2 (findings 76 and R7.14): which colour a taken fill's lane lights when two taken fills touch.** Today each highway instant decides its lane colour, and the draw code then colours a whole merged span with the colour of the first instant inside it. The two agree whenever a span holds one fill, which is every case anyone could show reachable. If two taken fills ever touched or overlapped (a fill starting on a half tick, or a second activation while the first's SP still runs), the second fill's lane would light in the first fill's colour. After the fold each span carries its own pad, so the second fill would light its own lane colour. Recommendation: take the owner's answer; it is what the engine says the second fill is, and no library record reaches the case.

No question for finding 75: `widest_word` and `wrap_words` differ only on text that starts with spaces or is all spaces, which the Preview never produces, so taking `wrap_words`' answer changes nothing drawn. No question for finding 206: the hydra_batch header keeps its exact lines; only `hydra_bench`, a dev tool, changes words.

### 4b. Decisions that change nothing on screen but are not in any decision record

These are not display or record changes, so they do not need a game-terms question, but no decision names them, and the implementers should not pick silently.

- Finding 220: when `3d-config.json` lacks a key, the loader refuses with an error naming the key, instead of falling back to a header number that no longer exists. Recommended, because ADR 0008 already says the json owns the numbers and the shipped file always has every key.
- Finding 207: the chart-file check and the report-file check share one 2-second interval and one caching helper. Both are 2.0 today (recorded under D48 Q33 and the C4b scan row), so nothing moves; the call is only whether they may ever be tuned apart. Recommended: one interval.
- Finding 340: "is the overlay the selected path's" compares the path part and ignores the cap, exactly as today's prefix match does. The exact-match alternative would stop Show in Preview from jumping while a new cap's overlay is still building. Recommended: keep today's behaviour behind a named method.
- Finding 210: at startup the UI scale comes from Hydra's `ui_scale_for_dpi` instead of the ImGui backend's. They agree at every real DPI; at a reported DPI of 0 the backend gives 0 (an unusable window) and Hydra gives 1.0. Recommended, and not worth a question.
- Finding R7.13: `toggle_at` is deleted, not kept as a test oracle, because D42 forbids frozen reference copies. The truth-table test calls the sweep.
