Facts that hold for most records:

- The Path Builder is not captured. `records-screen/index.md`, "What is not captured", lists "the Path Builder" as missing. So every claim about what a Path Builder window, row, card or clock shows is "claim not checked", and needs a capture of that window.
- Burnout (`corpus::burnout_notes`), White Washed and Set the World on Fire are not among the seven dumped charts. Their engine records are missing too. Smash Mouth's "I'm A Believer" is one of the seven (`believer.dump.json`, `believer.schedule.json`, `believer.path4.schedule.json`), which helps `choose-an-ending` only.
- The file headers (`pbtest_build.cpp:5-8`, `pbtest_coach.cpp:1-3`) say "Every tick, sentence, clock and figure is pinned from one run". That is a snapshot admission, and the rubric's "Two kinds of number" rules snapshot numbers out.
- The display words these tests read are built from engine values: `fill_reason`, `step_short`, `end_choice_text`, `hydra_end_sentence` (`pb_text.cpp:49-183`) read `Activation::window_end_tick()` (`model.cpp:717`, from `sp_end_steps`), `app::activation_badges`, `core::after_sp_end`, `Activation::sp_meter()`. The display does not invent an SP end here. The one value the display works out from its own curve is "phrases saved" at an unplayed fill (`bars_saved_at`, `pb_text.cpp:45-47`, `app::sp_meter_bars_at` over the Preview's own meter curve); `tests/single_owner/rules/pathbuilder/activate-line.json:5` names `fill_reason` as its owner. I did not judge whether the engine has its own answer to that question. Not read: `src/app/preview_view.cpp:125-220`.
- All tests of `hydra_pathbuilder_uitest` run in one process when more than one `--test` is given (`pbtest_main.cpp:66-77`); there is no `--all` (`docs/agents/ui-testing.md:151`). `hydra_uitest` gives each test its own process (`tests/ui/uitest_main.cpp:15-19`). So the pb tests can see each other's state, and their own comments say so: "The pointer is wherever the last test left it" (`pbtest_build.cpp:316`), "the pointer must not stay on the fill" (`pbtest_coach.cpp:135`).
