## Roadblocks
- Measurement workers said they would report once a background job finished, then went quiet -> they had parked themselves behind background shell jobs that never woke them -> worked around: sent nudges and told them to finish in the foreground
- A GPU decoder run on an AV1 video hung for 23 minutes, and a benchmark loop kept starting new hung decodes for about two hours -> the brief read the codec from the file name (.webm meant VP9) when the file was really AV1 -> fixed: killed the loop and its child processes, and added a watchdog that warns on any ffmpeg run over 15 minutes
- Agent T6 went past its scope: it changed spdisc.py and reworked the HUD gate (the step that finds the on-screen panels), which its spec never named -> the spec listed owned files as plain text and reviewers judged results, not file lists -> fixed: every review now checks the changed files against the owned list with git diff
- The speed target for task R1 (the brightness rewrite) failed review -> the profile it was set from ran while other processes loaded the CPU -> fixed: the change was accepted once its output was proven identical, and the workflow script was edited and resumed
- Agent T6 blamed another session for its own patch scripts and a commit amend -> those edits did not show in its own view, and the editor's 'modified on disk' notice looked like an outside writer -> fixed: specs now require git reflog proof before naming another actor, or else 'origin unknown'; a real outside edit did happen too, but it was not the amend
- A GPU crop test (crop_cuda, a 2019 FFmpeg patch ported to a current build) showed no speed gain -> copying the cropped frame back to system memory cost more than the crop saved -> dead end: the output matched the CPU crop, but the patch was rejected; the full-frame GPU copy-back and the Vulkan route were slower still
- Hydra.exe was running, which blocked the relink and the install -> the running app held its own files -> worked around: built in a separate build folder; the user runs the installer later
