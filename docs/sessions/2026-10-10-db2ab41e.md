## Topics
Library column widths, the width rule, ImGui table state, the path report window, a git merge slip, rebuilding Hydra.exe, review, handoffs.

## Roadblocks
- Library columns were squeezed to header width at 2,560 px -> one 1,128-character Best path outlier made that column look far wider than it is, so the width rule gave it most of the room -> fixed: each column now takes the width that fits 99 of every 100 rows, and spare room goes to the columns still cut.
- Charter and Folder started hidden at startup -> the saved ini overrode the panel's show setting -> fixed: the panel's choice of shown columns now waits until the table is past its first frame.
- A width that ImGui changed stayed wrong -> our code only re-sent a width when its own answer changed, so ImGui's own changes (it clamped hidden columns to 4 px, the Width=4 lines in the ini) were never put back -> fixed: any width ImGui changes is now sent back, so the squeezed state cannot stick.
- A column-shown test copied ImGui's own, and a second settled check existed -> the rule task wrote both as copies -> fixed: the reviewer kept one owner for each and added a scan rule that catches a second copy.
- A refused merge was never cancelled, so git kept its merge-in-progress state -> another session's doc commit on main became a merge with the join branch, and main's history then claimed the fix was merged; a normal merge later would have dropped it -> worked around: merged main into the join branch by hand at its true fork point, checked the result in both directions, and sent it to a second reviewer.
- The odd 0 in Hardest ms looked like it used different code -> we first assumed that column drew differently -> dead end: both columns use one formatter and get identical text, size and position, so that idea was dropped.
