## Roadblocks
- The ffmpeg watchdog would not start -> the auto-mode classifier refused its process-killing loop, and a bash shell stripped the dollar signs from the PowerShell command -> fixed: the loop went into a .ps1 file, which then ran.
- Swim decoded to different pixels on the processor and on the card -> ffmpeg's colour step rounds the yuv420p and nv12 frame layouts differently, and NVIDIA's h264 parser builds some B frames (predicted frames) wrong in the fade-out -> fixed: a yuv420p step before colour conversion, and h264 never decodes on the card (task F3b).
- The AV1 crop came back two rows low on the card -> cause not found -> fixed: every crop is rounded down to a multiple of 16, and the first frame is checked against the processor.
- The windowed alignment was claimed byte-identical to the whole-track decode, and it was not -> the two paths resampled audio differently, and a seek into Ogg audio (a file format) can start a few samples off -> fixed: task F5b trims windows by sample count and decodes each one twice from different starts, keeping only results that agree.
- The chain ran the tasks one after another -> every task shared one checkout, and two agents cannot work on different branches in one folder -> fixed: each parallel task got its own git worktree (a second working copy of the repo), in three stages.
