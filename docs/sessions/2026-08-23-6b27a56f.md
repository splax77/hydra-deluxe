# Video player audio/interface drift bugs (2026-08-23)
session: 6b27a56f-6972-419b-9c73-e7a8246ce0d1 | project: hydra-test | commits: 19cc296, eeb5d38 | D: none | tags: preview, transport, tests, release, analyze | agents: 0

## Goal
The user wanted two bugs in the video preview explained and fixed: the audio going crazy when the time bar is click-and-held, and the volume drifting while the interface shifts. Later the user asked for the fixes to be released as v1.6.2 on GitHub.

## Topics
preview playback while scrubbing, time bar hold, proportional-font layout drift, fixed-width text slots, analyzing and scanning modals, UI test macro trap, version bump and release

## Roadblocks
- The first video analysis stopped partway with "Connection lost mid-response" -> the API connection dropped -> worked around: the user said "Try again" and the frames were re-cropped at 5 fps
- The time bar hold made a flat buzz in the audio -> the clock kept running during the hold, so the slider re-seeked the same spot about 60 times a second -> fixed: playback pauses while the bar is held and resumes on release (set_scrubbing in preview_controller.cpp)
- The volume slider and buttons moved while digits changed -> the UI font is proportional, so a wider number pushes everything to its right -> fixed: changing text now sits in a fixed-width slot sized for its widest value (helpers in widgets.h), across the transport row, both modals and the top buttons
- The float checks in the existing preview test ignored their tolerance -> IM_CHECK_FLOAT_EQ_EPS is a two-argument alias in this engine version, so its epsilon was silently dropped -> fixed: switched those checks to IM_CHECK_FLOAT_NEAR_EQ
- The first version bump landed inside the fix commit -> the release convention keeps the bump as its own "Hydra 1.6.2" commit -> fixed: split it into two commits before tagging
- The relink failed because Hydra.exe was locked -> the dev build the user had open was still running -> worked around: closed it (settings were already saved to the INI) and rebuilt

## Rulings
- "in onyx this simply pauses the playback" (13:24 UTC, the wanted behaviour for a click and hold on the time bar)
- "interface drift is an issue throughout the UI and needs to be addressed" (13:24 UTC, widens the fix from the time bar to the whole UI)
- "now push this to github as v1.6.2" (13:41 UTC, approves the release as version 1.6.2)

## Outcome
Fixed both bugs, with three new UI tests that failed before the fix and pass after. Pushed to GitHub as v1.6.2 with Hydra-1.6.2-setup.exe attached.
Two commits went out: the fix (eeb5d38) and the "Hydra 1.6.2" version bump (19cc296), plus the annotated tag v1.6.2.
