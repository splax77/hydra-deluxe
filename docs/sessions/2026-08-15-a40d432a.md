- Screenshots showed the chat window, not Hydra -> the capture grabs whatever is on top of the screen -> worked around: bring Hydra to the front before each capture.
- Song Details popup opened once, then nothing clickable after it was closed with its X -> the close path never reset the app's show-details flag, and the open trigger only fires when that flag turns on, so it never fired again -> fixed: the open state is now checked every frame in details_view.cpp, not only inside the popup's success branch.
