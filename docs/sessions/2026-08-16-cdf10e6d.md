## Outcome
Ended normally at 01:45 UTC with Hydra reading Clone Hero's bundled .srb songs end to end. Nothing is committed.
An .srb is a 16-byte header followed by two raw DEFLATE streams. The first is metadata (filename, title, artist, album, genre, charter, year, description). The second is a standard notes.mid or notes.chart. The agent reached this by probing the binaries, since the game is IL2CPP and cannot simply be decompiled.
