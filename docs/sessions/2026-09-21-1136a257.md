## Goal
Count the ghost and accent notes in Periphery's Wildfire chart by pad and type, then add that breakdown to Hydra as a Dynamics tab in Song Details and store the counts in the database, shipped as v1.7.10.

## Topics
Chart dynamics (ghost and accent notes), a MIDI counting script, a Dynamics tab mock, the Song Details tab layout, 2x kick counts, stored dynamics rows in hydra.db, UI test, colour fix, user guide section, release 1.7.10.

## Outcome
Ended with the Dynamics tab and the stored counts shipped as v1.7.10, in one commit ec3ade9 that was pushed with its tag and a GitHub release.
The commit holds the tab, the stored counts, the version bump to 1.7.10 and a Dynamics tab section in the user guide. The release carries the 33 MB installer Hydra-1.7.10-setup.exe.
Before shipping: the full build passed, the doctest suite passed at 277 cases, and all 14 UI tests passed, including one that reopens the tab and checks it does not parse the chart again.
The counts were checked against a separate MIDI recount of Wildfire (254 ghosts, 130 accents, no 2x kicks) and of Acid Romance. Every cell matched.
Storage: a new dynamics table in hydra.db, keyed by chart md5, difficulty and Pro Drums. Counts are saved on first view, or during analysis when 2x Bass is on.
Untracked scratch files from earlier sessions were left alone.
