# Hydra crash on starpower reanalysis (2026-08-23)
session: 898c13d4-1190-4cf1-9cca-ae803d662ad7 | project: hydra-test | commits: none | D: none | tags: sp-cap, analyze, record, tests, agents | agents: 1

## Goal
Hydra crashed when the user changed the Star Power cap and reanalyzed a song. The user asked for the source of the crash and a fix, using a screen recording of the crash as evidence. The session fixed it, added a regression test, and moved the modal's statics into the app state after the user said to go ahead.

## Topics
Star Power cap box and reanalysis, dangling pointer in the Song Details modal, record generation counters, std::bad_alloc from a freed record, hydra_uitest regression test cap-switch, process-unique Generation counters, DetailsViewState moved into AppState

## Roadblocks
- Hydra aborted about two seconds after the cap box changed from 5 to 6 -> the modal kept a static pointer into the viewed record, and the cap box refreshed that record later in the same frame, freeing the old one, so the details kept reading freed memory -> fixed: the pointer is re-synced a second time right after the cap box is drawn, and a cap-switch regression test was added (it failed 3 of 3 before the fix and passed 3 of 3 after).
- After the fix, the cap-switch test failed inside the full UI run -> the test runner builds a fresh AppState per test, but the view's static watchers persisted, and every counter restarted at 0, so the new app's first result looked already seen and was dropped -> fixed: Generation counters start process-unique. A real Hydra process has one AppState, so users were not affected.

## Rulings
- "make that change" (02:38 UTC, approves moving the modal's eight statics into a state struct owned by AppState)

## Outcome
Ended with the crash fix, the regression test and the refactor all uncommitted in the working tree on hydra-test.
Verification: hydra_uitest --all passed 5 of 5, twice in a row, and the original repro script passed 3 of 3. hydra_tests passed all 152 cases (28,107 assertions). build-cpp\Release\Hydra.exe was rebuilt.
The eight statics in the Song Details modal now live in DetailsViewState, owned by AppState as details_ui. The session reports no change in behaviour, labels or widget order.
