## Roadblocks
- The assistant said PC-Control could read Hydra's controls -> Hydra is drawn with Dear ImGui (a UI library that paints the whole window as pixels), so Windows tools see no buttons -> dead end: PC-Control would fall back to OCR (reading text from screenshots); the assistant retracted this and the memory note says not to suggest it again.
- The helper's mcp package could not see cryptography under the isolated mode that .mcp.json uses -> cryptography was only in the per-user Python folder -> worked around: the same version was also installed in the system Python, so the machine has two copies (harmless, the user was told).
- The first recommendation kept two line numbers for one failed line, one from Hydra and one from the helper -> the assistant did not see that they clash -> fixed: the user rejected it; live replies drop line numbers, the helper numbers its own script, and script mode keeps "failed at line N".
- Hydra and the helper each read timeout and wait numbers their own way (C atof for Hydra, Python float for the helper), so timeout 90s meant 90 to Hydra while the helper kept its 30 s cap -> the helper copied Hydra's rules because no owner was named when the build was split across two agents -> fixed: Hydra reports the timeout in force in every reply, refuses bad numbers, and refuses a wait longer than the timeout; a boundary audit found 12 such copies.
- A rare hang when the attached-mode connection shut down, shown under a forced 10 s delay -> a shutdown race in the connection code -> fixed: the process now exits in about 1 s.
- The T2 Python test failed while the C++ was fine -> the test itself was wrong -> fixed: the T2 reviewer fixed the test.
- The full-suite count fell from 1,409 to 1,397 C++ tests and the GUI count rose from 98 to 99 -> a parallel session's merge removed the old database-upgrade tests (about 730 lines in test_store_open.cpp) and added a GUI test -> worked around: the session reported the new counts and named the cause.
- The installer build still contained the text --uitest -> cause not found -> fixed: the T5 reviewer signed off and the main session checked the shipped exe, which has no test flags.
