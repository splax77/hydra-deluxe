## Outcome
The three-build limit is merged to main and to the hooks repo, and nothing is pushed.
Builds now need a pass from the hydra_build_pass tool. The tool gives a pass only when a slot is free, and one session may hold one build at a time. Agents are refused that tool. In tests, a direct cmake --build run and a plain build_cpp.ps1 run were both refused without a pass. A real build with a pass took 138 seconds, and the whole hydra_tests suite passed. The docs check passed on main, 18 of 18.
