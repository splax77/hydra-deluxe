## Roadblocks
- Cards cut rulings and roadblocks to fit a 45-line cap -> three of ten big sessions ran out of room -> fixed: cap raised to 60 (4f18f31); a test had built an over-long card by adding 30 lines, so it was tied to the cap itself.
- The brief told writers to avoid double quotes, which cost rulings, and the checker cannot match clicked-answer labels that contain quote marks -> the brief rule was wrong and the checker pattern is too narrow -> worked around: the brief allows plain quotes now, and labels with quote marks go in plain words under Outcome until the sc-5-fixes branch is merged.
- Five Haiku writers called tools the brief forbade, such as stray task chips and browser calls -> a brief rule alone does not stop a writer from using tools -> worked around: the brief names only the tools writers need, and the handoff recommends a dedicated card-writer agent type with read, search and write tools only (not built).
- The condensing step dropped 99 messages typed while Claude was busy, 20 refusal reasons and 4 slash commands with arguments -> they are stored differently in the transcript than normal messages -> fixed: the reviewer changed condensing to keep them (merged 9400a2b).
- Commits were missing from cards, because condensing records a commit only when its hash appears in tool output -> quiet commits and release scripts leave no trace -> worked around: the link can be rebuilt from git later, by the Session trailer for recent commits and by date for older ones.
- Agent counts were too low, because condensing counts only agents launched directly -> a session with 19 workflow agents showed 1 -> worked around: writers give the real number in words under Outcome; the counting fix is on the sc-5-fixes branch and is not merged.
