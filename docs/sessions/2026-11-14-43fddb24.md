## Outcome
Ended at 01:03 UTC with the plan settled and waiting for the user's go before seven executors start on it.
The scouts found no change in anything Hydra models. Chart reading, the note list, hit windows, fills, Star Power, scoring and the star thresholds all match between the two builds. Every game address moved, and the drum engine gained two fields, so the fields after them sit 16 bytes later.
Changes in the game that do not touch Hydra: Lefty Flip now remaps each drum hit's strength along with its pad (matching the official release note); online play sends live match events; a new input-recording format (CHIS) is not saved to any file yet; three built-in songs were re-packed with their notes unchanged, while the Discovery audio grew.
The Star Power scout found the solo-bonus function that page 06 marks as not found. It is in both builds, and its formula matches the page's rule.
The plan is on branch claude/plan-ch-6161 as docs/superpowers/plans/2026-11-13-ch-6161.md, not merged. It has seven tasks that can run in parallel, one address table per build, and nine small live checks on Edge Walk Pair.
Nothing was built or committed outside the plan branch. The code dump of the new build is kept locally.
