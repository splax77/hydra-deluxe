## Goal
Find out why the "Best all-0 path" section had disappeared from the Paths tab, for Slander and others. Bring it back under the 2.0 rule, where a 0 ms timing still counts as no timing. The user had said the section was an intended feature that should always show.

## Topics
best all-0 path section, the 0 ms timing limit, the E3 search change from Oct 4, squeezes and early fills, the section's hint text, Stale marking of library records, derive-once review, merge, push and rebuild

## Roadblocks

- The session first framed the question as whether a 0.0 ms timing still counts as timing -> the earlier decision was asked narrowly, and the list of lost sections came from test charts only -> fixed: the user restated the intended rule, and the session saved it as a top rule in memory.
- A reviewer found the same 0 ms check written in two places, and two docs describing the old rule -> the implementer's copies had drifted apart -> fixed: one shared function with a scan test, and CONTEXT.md and the differences doc were corrected.
- The app build failed because Hydra was open from build-cpp, which locked its exe -> the running app held its own exe -> worked around: the full suite ran on the test binary, which built fine. The app was rebuilt after Hydra was closed.
