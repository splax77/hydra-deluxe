## Outcome
The session ended with a plan, a tasks file and a handoff written for the next session. No code was written and nothing was committed.
The cutoff rule from the game (version 1.1.0.6142, as installed): cutoff for N stars = ceil(base score x multiplier), with multipliers 0.1, 0.5, 1.0, 2.0, 2.8, 3.6 and 4.4 for 1 to 7 stars. The game stops counting at 7. The table holds two more values, 5.2 and 6.0, which the counter never reaches.
Base score: 50 per gem, 65 for a drum cymbal, ghost and accent notes doubled, and sustains at 25 points per beat. The official wiki and the CHOpt tool agree with the game for 3 to 7 stars.
Correction made later in the session: the 32-bit float rounding only changes a cutoff when the base score is not a multiple of 5. Drum base scores are always multiples of 5, so for drums the float and exact results agree.
The plan has three tasks: (1) a new src/core/stars file with the table and the cutoff function, plus unit tests; (2) the Stars tab after Dynamics, with an extra column for the full solo bonus and GUI tests on two songs; (3) the user's visual check after a rebuild. The files are docs/superpowers/plans/2026-09-27-stars-tab.md, its .tasks.json file, and docs/handoffs/2026-09-27-stars-tab-handoff.md.
The memory note ch-star-cutoffs was written and then updated.
