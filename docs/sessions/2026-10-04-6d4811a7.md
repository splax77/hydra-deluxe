## Goal
Make the analysis path read only the notes part of a .sng or .srb chart file, not the whole file, so a whole-library batch uses far less memory. The results must not change.

## Topics
container loaders for .sng and .srb, ranged file reads, peak memory in a whole-library batch, derive-once review rounds, shared test helpers, ADR 0024 read sizes, worktree cleanup
