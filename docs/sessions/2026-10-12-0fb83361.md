## Outcome
The session ended with the brainstorm written out, with no code written and nothing committed.
The proposal: an activation is a window of time in which pressing the button gives the same score, so each guitar activation reduces to a few facts (phrases banked, first covered note, last covered note, whammy). The path string would reuse CHOpt's format, such as 2-2(+1)-3, and each activation would add its window width in ms. A narrow window is a squeeze, so the width would feed Hydra's existing squeeze ratings. The Preview highway would get a five-lane mode with a shaded window band, and a draggable activation marker to show the score change.
The session read CONTEXT.md and CHOpt's public path guide and README as sources.
