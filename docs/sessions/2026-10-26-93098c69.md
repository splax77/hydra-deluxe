- The test UI runs with Score range at 2, so the pictures showed non-default settings -> the test UI sets this to keep batches fast -> fixed: the capture script resets the settings to defaults before it analyzes.

- A caption named a yellow note while its picture showed a green cymbal -> the caption wording was wrong -> fixed: the reviewer reworded the Paths caption to name the yellow note.
- The dmleaderboards shot would need a real player name -> headless mode only draws a made-up player with one score -> dead end: the shot was dropped on the user's answer.
