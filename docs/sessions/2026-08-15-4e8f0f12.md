## Topics
library table borders and colours, song-info icons, multiplier-squeeze help text, path-row spacing and font, comma-grouped score numbers, DearPyGui colour baseline, disabled button and input colours

## Roadblocks
- Path rows like 1- 0 0 E0 stayed too close together after the first fix -> the first guess was table cell padding, which was wrong -> fixed: the real cause was the font. The original's score tree node passes its mono font down to every row, and the port only applied it to the header, so the rows fell back to a narrow font.
- The port kept ImGui's dark defaults for every colour the Python app did not set -> ImGui's blue-grey baseline differs from DearPyGui's neutral grey -> fixed: copied the baseline values from DearPyGui's own style editor, and checked them against screenshot pixels.
- Disabled buttons and inputs faded out in ImGui, while the original shows flat grey, and the input's plus and minus buttons were missed at first -> ImGui fades disabled widgets by default, and the stepper buttons take their own colour -> fixed: added flat disabled-colour helpers, then applied them to the stepper buttons too.
