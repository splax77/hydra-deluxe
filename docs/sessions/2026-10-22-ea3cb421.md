## Goal
The user could not see the squeeze timing for Star Power activations on The Age of Betrayal, because a collapsed activation row showed only one badge. The user asked for a change so that each collapsed row shows its squeeze timing next to the early fill. Later the session also fixed the badge layout, the one-font rule for the row, and the pill width, then merged and pushed.

## Topics
squeeze-in and squeeze-out timing, activation row badges, Paths tab layout, narrow panel wrapping, row font choice, shared pill helper, real-app screenshots, merge and push to main

## Roadblocks
- The squeeze on rows 1 and 2 was hidden -> a squeeze at 0 ms or below counts as needing no timing, and the 0 ms early fill took the only badge -> fixed: each activation now lists every timing, one badge per timing.
- Two parallel builders each made a temporary edit to the same line of paths_tab.cpp -> the two edits clashed when joined -> fixed: the session resolved the line by hand on the join branch.
- The narrow-panel screenshot looked bad -> the dropped badges had no gap above, were pushed to the right edge, and "3 bars" sat a few pixels low on main, because it used a different font -> fixed: badges now sit under the measure with the normal gap, and "3 bars" lines up with the measure.
- Different pieces of text on one row used different fonts -> the session had treated it as a baseline offset to patch, which the user rejected -> fixed: the whole row now draws in the mono font, and a separate session is building one owner for fonts.
- Each pill was as wide as its own text, so stacked pills had ragged right edges -> the pill look was typed inline in two places -> fixed: one shared pill helper and one width per row.
- The narrow screenshot was enlarged 2x before it was sent, so the two sizes looked different -> the session's own mistake -> worked around: the session measured pixels in both captures and sent later captures at the same scale.
- The Hydra helper could not copy the library database while Hydra was open -> the copy tool refuses an open database -> worked around: Hydra was closed before the real-app capture.
