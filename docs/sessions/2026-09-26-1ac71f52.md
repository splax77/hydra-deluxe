## Outcome
The session ended at 01:59 UTC with a plain-English answer to the three questions. No repo files were changed, and nothing was committed.
The hit window is recalculated for each note from its spacing. The earlier session's live data showed nine distinct values, from about 96 ms to about 171 ms total width, and each one matches the formula with the constants read from the running game.
The widest value seen, 171.43 ms, is what the formula gives for notes 170 ms apart. That suggests the spacing is capped at 170 ms. This is not yet tested.
The fixed 85 ms value in the engine did not change during play. For Hydra, the session recommends keeping the fixed 85 ms until the edge-walk test is done.
