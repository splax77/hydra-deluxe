- Hits read as misses -> the field at 0xb0 is the combo counter, which resets when any note is missed -> fixed: read the score field at 0x94 instead
- Claude rotated the pad keys from a guess about the highway video, and ignored the bindings screenshot the user had already sent -> the lane order on screen was taken as the key order -> fixed: reverted to the bindings screen and the registry values

- The pad-flash video seemed to show only three keys working -> the frames were sampled at 3 to 12 fps, but a pad flash lasts about one frame -> fixed: re-measured at 60 fps, and all eight keys light their pads
- Yellow, blue and green notes all missed, toms and cymbals alike -> the parser read the 110 to 112 markers backwards (a marked gem was called a cymbal) -> fixed: swapped the rule, so a marked gem is a tom; note counts (422 blue gems unmarked, 44 marked) fit a real drum part
- 2x kicks missed -> MIDI note 95 was not in the parser's allowed list, so 302 notes were dropped -> fixed: note 95 now maps to the kick key L, since notes 95 and 96 never share a tick
