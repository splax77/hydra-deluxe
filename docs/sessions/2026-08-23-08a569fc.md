## Roadblocks
- Reddit post could not be fetched -> the fetch tool and the browser are both blocked from reddit.com -> worked around: the user pasted the post text into chat.
- Hooks are not told which model is running -> the hook input has no model field and there is no model environment variable -> fixed: each script reads transcript_path and takes the model from the last assistant turn.
- Model lookup broke on one-line transcripts -> Get-Content -Tail returns a bare string for a one-line file -> fixed: wrapped the call in an array cast.
- Bash tool halved literal backslashes in one-liners -> the tool halves backslashes before the shell sees them -> worked around: wrote scripts with the Write tool and let PowerShell build the JSON-safe string.
- A big inline script in settings.local.json failed twice with an Invalid number JSON parse error -> cause not found, the same JSON checked valid in isolation -> dead end: inline scripts dropped in favor of .ps1 files that settings call with -File.
- Advisory text did not make Sonnet or Haiku agents appear -> a hook can only allow, deny or ask on a call that is already happening -> worked around: a soft counter asks once after 4 inline files, and a marker quiets it after a worker is dispatched.
- Fable gate denied the Opus executors that its own message told Fable to dispatch -> it never checked for a subagent caller -> fixed: added an agent_id exemption, after the permission classifier refused the hook edit and the user said to retry.
- The first no-recursive gate would have blocked the main Sonnet session from dispatching normal agents -> it ignored whether the call came from inside a subagent -> fixed: the gate now acts only when agent_id is present.
- In an audited session, the per-edit Opus agent hook made each edit wait 20 to 87 seconds, about 30 of a 56-minute run -> it ran on every Edit and Write -> fixed: review moved to SubagentStop, once per subagent.
- In an audited session, executors never spawned workers -> subagents never see posture text and Fable specs never mentioned delegation -> fixed: a gate denies Opus dispatches whose spec has no Delegation section.
- In an audited session, a Fable executor appeared -> a dispatch with no model field inherits the parent model -> fixed: a gate denies any dispatch without an explicit model.
