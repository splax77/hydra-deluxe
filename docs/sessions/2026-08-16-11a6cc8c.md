# Hydra chart visibility issue (2026-08-16)
session: 11a6cc8c-0cc2-4df5-8058-2fd841730f67 | project: hydra-test | commits: none | D: none | tags: chart, library, tests | agents: 0

## Goal
The user asked why Hydra did not see the Blood Doll chart from a Rock Band rip. Hydra found the folder but analysed zero notes. The session then fixed the parser and checked the other failed charts.

## Topics
MIDI parsing, running status after meta events, track names, batch analysis failures, checking 71 failed charts against their files, the stored records database

## Roadblocks
- Blood Doll analysed with zero notes, so Hydra reported no Expert drums -> the C++ MIDI reader reset its running status to the meta byte, so note data after a meta event was read as more meta data -> fixed: parse_track keeps the running status for channel messages only (src/parse/midi.cpp), with a regression test.
- After that fix, 14 of the 71 failed charts still had no notes -> the track held two track-name entries, PART DRUMS first and Drums later, and the C++ reader kept the last one, so the exact-name check in song.cpp skipped the track -> fixed: the first track name wins (midi.cpp), with a regression test.
- The 71 failed charts could not be listed from batch output -> batch failures are printed, not stored -> worked around: took the library charts with no stored record from a copy of the live database.
- An unintended hydra_paths.html appeared in the repo root after running hydra_report with no arguments -> the CLI usage had not been checked first -> fixed: the file was deleted and the CLI source was read for the right usage.
- Hydra.exe could not be relinked while the GUI was open -> the running GUI locked the exe -> worked around: the test and batch binaries were built first, and Hydra.exe was built after the user asked for a rebuild.

## Rulings
- "apply the fix" (18:18 UTC, approves the running-status fix in midi.cpp)

## Outcome
The session ended at 18:31 UTC after the rebuild, with both parser fixes built into Hydra.exe in build-cpp\Release.
