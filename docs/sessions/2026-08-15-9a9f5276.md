## Goal

## Topics

## Roadblocks
- The C++ score rows had grey highlight bars that the Python app lacked -> the tree headers used ImGui's framed flag, which paints a background -> fixed: the flag was dropped (item A2).
- The GUI looked slower than the old "under 10 seconds" figure for blink-182 -> the assistant guessed the GUI ran a slower engine, without measuring -> fixed: timed the exact call the GUI makes; the fast engine was already in use (0.45 s capped, 5.4 s uncapped with Limit timings off).
- The uncapped discography took 344.7 s at the default settings, with Limit timings on -> the 10 ms limit keeps timing-variant paths in separate buckets, which switches off the fast path in reduce_group, so the search grows about 60 times -> worked around: untick Limit timings to get the same best path in 5.4 s; the slowdown with the limit on is still unfixed.
- The C++ port had no ladder time budget, because the budget was turned off to keep golden tests deterministic -> the port had dropped Python's 120 s budget -> fixed: the budget is on for the uncapped edition only, and the tests still pass with it off.
