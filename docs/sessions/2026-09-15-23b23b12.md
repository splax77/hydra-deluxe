## Outcome
The session ended with a written diagnosis and no code change: it wrote a handoff note and a memory pointer, as the user asked.
The cause it found: a Star Power window that is capped by the cap rule ends on the last phrase collected, not on the activation. The collection note was hit 63.1 ms early, and the squeezed phrase note was hit 67.3 ms late; the session summed these to 130.4 ms, which clears the 115.4 ms gap.
