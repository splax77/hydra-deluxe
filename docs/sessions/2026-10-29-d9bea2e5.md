## Goal
The user asked for a brainstorm on an interactive Path Builder: a separate program, shipped next to Hydra, where a player can try their own path, see what each choice costs, and learn why the best path is best. The session produced a design spec and two build plans, one for the builder and one for splitting Hydra into reusable libraries. Nothing was built.

## Topics
path builder brainstorm, rhythm-game path tools (scout), explain-the-optimum ideas, Coach vs Calculator vs Explainer sizes, cost per choice (new engine option), colours for costs, path notation, program name, library split for reuse, planning and review
