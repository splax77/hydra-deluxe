# Analysis performance regression (2026-10-05)
session: e5c08fba-66a5-441a-a12a-bb4d1d11dc99 | project: hydra-test | commits: 159e8ac, 1be6010, 46da17d, aacb493, d57f373 | D: D69, D75, D141 | tags: performance, analyze, library, agents, hooks, review | agents: 5

## Goal
Find out why analysis got much slower than the 2.0 release (the user said 10 times), and fix it. The session also fixed two hook problems the agent fleet hit: a hand-back blocked by the budget hook, and a stall watchdog that flagged finished agents as stuck.

## Topics
analysis speed, where song length comes from, reading audio length (Ogg, Vorbis, Opus, MP3, WAV), song.ini and .sng and .srb metadata, Preview scrub bar and Star Power meter, parallel agent split and audit, budget hook, stall watchdog, worktree cleanup

## Roadblocks
- Analysis ran slower than 2.0 (the user saw 10 times; the whole-library timing showed about 2.7 times) -> every song's length came from reading its full audio, which D69 made the one source -> fixed: D75 reads the length from the chart's metadata first, with the last Expert drum note as a backup. Analysis now takes 17.5 to 18.2 s against 24.2 s for 2.0.
- The Preview agent reached 185 tool calls against a cap of 150 and never delivered its report -> the budget hook did not let SubagentHandback through after the cap, and denied attempts still count toward the tool total -> fixed: the hook now lets the hand-back through after the cap, with a test that failed before the fix. The counting was left alone, as the user asked.
- The stall watchdog kept flagging finished agents as stuck -> it did not count SubagentHandback as a finish, and real transcripts end with an extra attachment record -> fixed: it skips trailing attachment records and treats SubagentHandback like StructuredOutput, with a test.

## Outcome
Ended with the fix merged to main as aacb493 and pushed to GitHub, so analysis is now faster than 2.0 on the whole library.
Song length now comes from the metadata first: song.ini song_length, the .sng song_length key, or the .srb song_length_ms field, moved into chart time by the chart's delay or offset. Without a stated length, the last Expert drum note counts, 2x kick included. The Preview scrub bar and Star Power meter use the same length, and charts without audio now get activation dots.
The full C++ suite passed on main, 1,127 of 1,127. Hydra and its tools were rebuilt from main.
The budget hook and the stall watchdog live under the user's hooks folder, not in the repo. Both have fixes and tests there.
The two finished worktrees, sl1 and sl1-review, were removed after their branches were merged.
