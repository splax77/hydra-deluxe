## Goal
The GUI loaded icons and fonts with paths relative to the current working directory, so a shortcut with another Start-in folder could show missing icons and the default font. The user asked for those loads to build absolute paths from the exe folder, and for a check that the icons and fonts still render with the working directory set to C:\.

## Topics
exe-relative asset paths, icon loading in icons.cpp, font and app-icon loading in main.cpp, working directory launch test, window screenshot, worktree branch setup

## Outcome
The session ended with the fix built and checked in the real app, and the changes left uncommitted on the worktree branch.
All runtime asset loads now build paths from the exe folder: the icon PNGs in icons.cpp, and the app icon and both .ttf fonts in main.cpp.
