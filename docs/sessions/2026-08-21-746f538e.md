## Roadblocks
- The PowerShell tool reported a CMake configure as failed -> it wrapped a harmless deprecation warning from stderr as an error -> worked around: wrote the full log to a file and read the real exit code, which was 0.
- libogg would not configure under CMake 4.x, which dropped support for policy versions below 3.5 -> the vendored libogg asks for an older minimum -> fixed: set the policy minimum to 3.5 for the subprojects, with no edits to vendored files.
- The ogg and opus targets failed with MSB1009 -> cmake --build sends nested codec targets to the wrong project file -> worked around: ran MSBuild directly on the nested project files, and both built.
- The Phase 1 test song threw "Duplicate note." -> the test added a kick and then add_2x, which already adds a kick -> fixed: removed the extra kick.
- Phase 2 tests ran a stale exe after a compile error, and the hex escape \xD8art swallowed the letter a -> the test code had two type and escape bugs -> fixed: switched to read_file_bytes and split the escape.
