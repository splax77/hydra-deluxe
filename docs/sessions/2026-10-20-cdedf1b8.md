## Goal
The user saw a "?" in a song title and asked why. The session found that the chart author saved song.ini in an older Windows encoding, and Hydra read it as UTF-8. The session built a decoder that tries UTF-8 first and falls back to the older encoding. Then it shipped that fix as release 2.10.2.
