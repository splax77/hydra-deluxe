## Outcome
Ended with the spec and a planning handoff committed to main and not pushed, every question decided, and nothing built.
The design: one stored record per chart, a small table of settings profiles, and a separate table with each chart's top 5 paths. In a scratch copy, the results table went from 8.8 MB to 1.9 MB. The paths add an estimated 3 to 4 MB per profile, not measured yet.
Wording decided: the report says N charts and drops the word records; the Best path only box becomes Optimal paths only; the Notes count label becomes Note count; Average Multiplier is spelled one way on the Paths tab, the report and the Stars tab; the Analyze button reads Analyze shown (N)... when a search or chip narrows the table.
Clone Hero rules adopted: generated fills start on the measure line, one measure grid is used everywhere, Star Power counts partial measures continuously, and beat lines follow Clone Hero's grid. Scores move on charts where these differ; hydra_replay lists every changed test chart before merge.
