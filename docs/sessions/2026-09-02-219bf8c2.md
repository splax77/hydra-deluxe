## Goal
The user wanted a reusable workflow that takes a full-combo (FC, every note hit) gameplay video and reports the path played, the points lost against Hydra's best path, and where those points were lost. The reference video was Swim to the Moon, and later the user ran it on the Divine Inner Tension album video.

## Topics
video score-curve reading, the hydra_replay path scorer, Star Power end timing, frontend and backend losses, per-song HTML loss report, artifact publishing

## Roadblocks
- The first report's optimal score was a guessed number, not Hydra's total -> the tool took the executed path's windows from the disc, and an early activation dropped its end chord from the window -> fixed: windows now come from Hydra's stored path, so the ceiling is Hydra's own total.
- Swim's first result (12 losses, 3,900 points) was too low for the same reason -> the same disc-based windows -> fixed: a rerun shows 14 losses and 4,820 points.
- Loss notes were inferred from the disc, not read -> the tool guessed which notes were missed -> fixed: each loss now comes from the score counter's frame-by-frame steps, which name the notes.
- The report repeated each activation in chips and again in a table -> two places held the same facts -> fixed: one table per song, with dynamics losses listed once beneath.
- A concurrent session reworked how the engine stores Star Power end ticks, in the same working tree -> that marks every installed database row stale, and the repo now has 30 uncommitted files mixing both pieces of work -> worked around: the replay tool re-analyzes charts in memory, and the commit was left to the user.
- The in-app browser could not open the private artifact or screenshot a file outside the project -> it is not signed in, and it cannot reach files outside the project -> worked around: structure checks and an executor's own verification pass.

## Outcome
Ended with the Divine Inner Tension loss ledger published as a private artifact, after the fixes to the optimal score and the loss attribution.
Frontend means how late the disc lit after the activation chord. Backend means the points lost at the end of a Star Power window.
Swim lost 4,820 points across 14 losses against Hydra's ceiling of 2,451,465. Divine Inner Tension played Hydra's path 3, with a ceiling of 4,975,295 and 27 losses totalling 9,640.
The tools are fcvideo.py in video-tools, which reads the screen, and hydra_replay.exe in the repo, which scores every path. No commit hashes were recorded; the commit was left to the user.
