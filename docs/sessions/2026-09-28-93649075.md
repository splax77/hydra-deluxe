## Goal
Show each path's own hardest timing next to that path, and make the Preview keys and the library panel easier to use. The user then asked for more fixes, and the session shipped Hydra v1.9.0, v1.9.1 and v1.9.2.

## Topics
path timing display, Activations heading, Preview key bar, hide-library button, headline baseline, library column order after restart, song length backfill for the timeline, compiler warnings, settings row alignment, releases

## Roadblocks
- The Preview key hints were one grey run-on line that was hard to read -> the hint was plain text with no key shapes -> fixed: a keycap prompt bar, with each key drawn as a small box beside its action.
- The headline path sat higher than the big score -> ImGui places an item after SameLine at the top edge of the line, and the path font is smaller -> fixed: the path moves down by the difference between the two fonts' ascents.
- The word "Difficulty" in the settings row sat 8 px lower than the rest -> the code nudged the cursor, but SameLine items start at the top edge, so only that word moved -> fixed: each control starts its own line at the centred height.
- Sorting by Best path and restarting moved that column to the front -> ImGui reads a saved sort back wrong when reordering is off, an upstream bug in ImGui -> fixed: render_table in library_table.cpp resets the column order whenever ImGui loads saved settings, and a GUI test feeds in the saved line.
- Old saved results had no song length, so the timeline was missing -> the length was saved only at analysis time, and a saved result holds no notes -> fixed: opening such a song reads its chart in the background and saves the length (v1.9.1).
- Hydra.exe could not be rebuilt while the app was open -> the running app locked the file -> worked around: the test programs were built first, and Hydra was built after the user closed the app.
- 13 compiler warnings had built up in test code -> nothing turned warnings into build failures -> fixed: a read_env helper, a renamed variable, a type fix, and warnings-as-errors for Hydra's own code (cd1dbba).
