## Goal
The user wanted the top 10 sections in the whole Hydra library where Star Power drains slowest. After the first list, the user narrowed it to sections where Star Power is actually running.

## Topics
Star Power drain speed, seconds per SP bar, tempo and time-signature maps, stored best-path activations, hydra_replay dumps, library-wide chart scan

## Roadblocks
- The first plan was to read drain speed from the database -> the database does not store tempo maps -> worked around: a read-only Python script read the tempo and time-signature lines of every chart file.
- The first list ranked 19 charts that have no activations at all -> the filter checked tempo and notes but not Star Power -> fixed: the list was limited to charts whose stored best path uses at least one activation.
- Charts with Star Power still showed slow stretches where no Star Power was running -> the stored results keep only summaries, so the best path with activation times was not in the database -> fixed: 13 charts were re-analyzed on a scratch copy with hydra_replay, and only stretches with a note hit while Star Power was running were kept.
- Two charts did not parse in the scan script (the Beenox logo chart and two copies of Scale The Summit's Daggers & Cloak) -> cause not found -> worked around: left out of the list.

## Rulings
- "most of these charts dont have any starpower though. tighten the filter to only include charts with starpower" (14:31 UTC, drops charts with no Star Power from the list)
- "yes require starpower to be running" (14:35 UTC, approves the stricter test that Star Power must be running inside the slow stretch)

## Outcome
Ended normally at 14:37 UTC with a top-10 list in which each stretch has Star Power running inside it.
The top entry is Rolo Tomassi, Opalescent, verse_2a, at 34.3 s per bar (126 BPM, 36/4).
Nothing in the repo changed. The scan scripts and output (drainscan.py, spwalk.py, drain.json) were scratch files, not kept.
