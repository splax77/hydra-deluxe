## Outcome
Ended with a plain explanation in chat, with no files changed and nothing committed.
A cold read fetches the file from disk. A warm read uses the copy Windows keeps in memory. The cost is mostly per file (opening it, the folder lookup, often a Defender scan), so a library of thousands of small chart files pays it thousands of times. The answer also quoted older timings from memory notes: a serial scan that was killed after 10 minutes cold and finished in 12.4 s warm.
