## Goal
Add drum lane support to the Preview. A lane is a stretch the chart marks during a roll or trill, and Clone Hero shows it in the game. The user asked for a brainstorm first, then the build, a real-app check, and a 2.6.0 release.

## Topics
drum lanes in the .chart and .mid readers, which pads a lane lights, Onyx-style lane strips in the Preview scene, timeline and highway drawing, late-start lanes, whether lanes change scoring, parser fingerprint pins, the 2.6.0 release notes and installer

## Roadblocks
- The brainstorm called lanes display-only, a guess that no source had checked -> the web search found nothing, and the game code was not yet read -> worked around: a scout read the game code and found the drum engine reads lanes during play. A later follow-up session found lane notes score the same as normal hits.
- Two parse fingerprint tests failed once the parser began reading lanes -> the tests hash everything the parser produces, so the new lanes changed the hashes -> fixed: a reviewer repinned the two values from its own run.
