## Roadblocks
- The Hunyuan3D texture bake (2.1 PBR, then 2.0 mini+turbo) ran 12+ minutes on the CPU with the GPU idle, and the 2.1 run took about 90 minutes -> the bake was CPU-bound -> dead end: the AI texture bake was dropped (per the handoff); textures were cropped from the user's reference screenshots instead.
- A build script stopped on a harmless ogg deprecation warning -> the script treats anything on stderr as a failure -> worked around: ran cmake directly.
- The audio callback could not see the private Impl struct -> a free callback function cannot reach a private nested type -> fixed: a file-local user-data struct passed to the callback.
- A stb_image single-file library may only be compiled once in the program -> the icons code and the new highway code both needed it -> fixed: moved the one compile into a shared hydra_image library that both link.
