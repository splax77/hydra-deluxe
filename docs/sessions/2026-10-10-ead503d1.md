## Roadblocks
- A merge into main was refused by the git gate, and that left a half-done merge in the shared checkout for about 20 seconds -> the precheck ignored a `cd` inside the command, so it judged the folder the session was already in -> fixed: the precheck now follows a `cd` or `Set-Location` into the folder the command names (new test `test_h51_precheck_cd.ps1`).
- A merge check sat waiting for a permission click for about 6.5 minutes -> the rerun gate grouped unrelated commands under one label such as "Set-Location git", so it asked from the third run on -> fixed: the rerun gate was retired, with its list line, file and test removed.
- A branch that had been reviewed clean lost that review when main was merged into it -> the gate had no rule for a catch-up merge, so every catch-up needed a full review -> fixed: a clean catch-up keeps its review, and a hand-resolved one needs only a review of the resolution.
- Parallel branches kept conflicting in the same list files -> CMakeLists.txt listed every test file by hand, and scan rows sat in one shared array, so two appends at the end always clash -> fixed: CMake finds test files by pattern, and scan rows can go in their own files.
- The precheck refused `git merge --trailer` as naming five commits -> it counted the trailer text as branch names, and git has no `--trailer` option at all -> fixed: the precheck now says that plainly.
- One hook test, `test_h8_bash_gates.ps1`, failed in the full hook suite -> the overhaul session's new scratch-folder rule breaks it -> worked around: confirmed it fails the same way on the overhaul's main without these changes, and reported it to that session.
