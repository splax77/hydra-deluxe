## Goal
The user pinned Hydra to the taskbar and its logo became a generic icon. They asked whether it can be fixed and asked for research and findings.

## Topics
taskbar pin icon, embedded exe icon resource, icon_app.ico, window icon loading, working directory paths, AppUserModelID, CMake resource wiring

## Roadblocks
- Pinned Hydra showed a generic icon -> the exe never embedded an icon resource, and the window icon came from a runtime file load that pinning ignores -> fixed: hydra.rc and resource.h embed icon_app.ico into both exes, wired into CMakeLists.txt, and main.cpp loads the window icon from that resource.
- The window icon load used a path relative to the working directory -> a shortcut with another start-in folder would show a generic icon even while the app runs -> fixed: the same change, since the icon now comes from the embedded resource.
