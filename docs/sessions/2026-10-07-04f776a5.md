- In the UI test runner, frames piled up during long waits (one test reached about 1.3 GB) -> the software GPU was never waited for, so frames queued up -> fixed: flush the GPU every frame, which took that test's peak to about 200 MB.
- The Preview renderer left 24 device references where 2 were expected -> cause not found -> fixed: MEM-T's change, which passed a new leak test.
