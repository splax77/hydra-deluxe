Hydra Deluxe 2.13.2 rescans your library by itself when an older version scanned it.

**Your saved results carry over.** Nothing reads `Stale` after the update, and nothing is analyzed again. Scores and paths don't change.

**Update from the app.** If you run 2.12.0 or later, the bar at the top of the window offers this release the next time Hydra Deluxe starts; click `Update`. If you run 2.11.0 or 2.11.1 with its update check on, a line under the toolbar offers it once its daily check runs. From 2.10.2 or earlier, download the `-setup.exe` file below and run it.

**The library rescans itself when an older version scanned it.** 2.13.0 started reading each chart's album. But a library scanned by an older version showed no albums until you clicked `Scan library`. Now, when Hydra Deluxe opens a library that an older version scanned, it starts that scan by itself. The `Scanning charts` window says `An older version of Hydra scanned this library. Scanning again to read what this version adds.` This scan reads every chart again, so it takes about as long as your first scan did. If you already scanned with 2.13.0 or 2.13.1, no scan starts. If you click `Cancel`, the scan starts again the next time you open Hydra Deluxe. If a song folder can't be read, the scan waits, and a line under the toolbar names the folder.

**The User Guide has pictures.** The User Guide and the README now show the main screen and each tab of the song panel, taken on the test charts.
