**MIDI charts read their tracks the way the game does.** Clone Hero never reads the first track of a `.mid` chart as an instrument, so a chart whose only drum track is its first track has no drums in the game. That is the usual case for a one-track `.mid` file. Hydra Deluxe used to read drums from that track. Such a chart now reads `Can't analyze`, with a reason like `No Expert Pro Drums notes in this chart.` Practice sections now come from the first track named `EVENTS`, in any mix of upper and lower case, and from no other track, as in the game. Your saved results carry over: an affected chart keeps its old result until you click it, which analyzes it again, or until its file changes.
