**Hydra Deluxe now tells you when a new version is out.** Hydra Deluxe checks for a newer release once a day when it starts and tells you under the toolbar. Click `Update` to download and install it; nothing is installed until you do. Before it installs, Hydra Deluxe checks the download against the release's signature and refuses a file that doesn't match. Windows asks for permission to run the installer. Hydra Deluxe closes while the installer runs and opens again when it finishes. If you say no, Hydra Deluxe keeps running unchanged. `Skip this version` and `Later` hide the notice. To stop the check, untick `Check for updates` in `Analysis settings`, in the new `App` group. It starts on. This release is the first that checks, so the next release is the first one it can offer.

**Hydra Deluxe checks for updates each time it starts, and a bar at the top of the window shows your version.** The check now runs at every start of the installed copy, with no setting to turn it off. The `App` group in `Analysis settings` is gone, with its `Check for updates` box and its `Check now` button. If you unticked `Check for updates` in 2.11.x, the check runs again. The update line no longer sits under the toolbar. It moved into a new bar along the top of the window, which always shows `Hydra Deluxe <version>` for the version you run and whether you are up to date: a green dot and `Up to date`, or an amber dot and `Hydra Deluxe <version> is available.` when a newer release is out.
