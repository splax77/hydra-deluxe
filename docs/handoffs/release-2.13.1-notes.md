Hydra Deluxe 2.13.1 keeps each song's album on screen while a song is open.

**Your saved results carry over.** Nothing reads `Stale` after the update, and nothing is analyzed again. Scores and paths don't change.

**Update from the app.** If you run 2.12.0 or later, the bar at the top of the window offers this release the next time Hydra Deluxe starts; click `Update`. If you run 2.11.0 or 2.11.1 with its update check on, a line under the toolbar offers it once its daily check runs. From 2.10.2 or earlier, download the `-setup.exe` file below and run it.

**The album shows under the artist while a song is open.** Opening a song narrows the library to `Title`, `Artist` and `Best path`, and the `Album` column hides with `Charter` and `Folder`. In 2.13.0 the album then showed only while you searched for words, so a plain list of songs had no album at all. Now every row shows its album on a second line under the artist, whether or not you search. The rows are two lines tall, so the list fits about half as many songs. A song whose chart names no album leaves that line empty. While you search, album matches on that line are highlighted in gold, as before. The same line shows whenever the `Album` column is hidden, including when you hide it from the heading row's right-click menu.
