Hydra Deluxe 2.11.1 draws characters its own fonts don't have. Before, many of them showed as `?`.

**Your saved results carry over.** Nothing reads `Stale` after the update, and nothing is analyzed again. Scores and paths don't change.

**Update from the app.** If you run 2.11.0, a line under the toolbar offers this release; click `Update`. From 2.10.2 or earlier, download the `-setup.exe` file below and run it.

**Song names in every script read correctly.** Hydra Deluxe's own fonts cover Latin letters, and only the fixed-width text could fall back to a Japanese font. Song names in Japanese, Korean, Chinese, Thai and other scripts, and odd punctuation such as the `‐` hyphen, could show as `?`. Hydra Deluxe now borrows any character its fonts lack from the fonts Windows already has, in every part of the window. Emoji draw too, in one color.
