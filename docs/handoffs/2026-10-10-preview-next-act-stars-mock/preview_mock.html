What the code already gives us

The notation text already exists. The "Copy path" text is built by Activation::notationstr_verbose (src/core/model.cpp:561). It prints exactly your examples: "5", "5+ (100 ms)", "5- (100 ms)". The Preview would call that same function, so the rule stays in one place. Today the Preview copies the skip count but not the squeezes, so the change threads one string from the record into the box.

Several timings share one parenthesis. An activation with two squeezes reads "2+- (100 ms/50 ms)": the timings follow the symbols in order, and an early fill's timing comes first. Try the last two entries in the picker. Giving each symbol its own timing would be a new format.

What the ms means. For a squeeze it is how far off the hit must be: "+" is more than that many ms early, "-" is more than that many ms late (the Paths tab's sentences, path_view.cpp:133 and 155). A zero or negative number means the squeeze is free. For an E it is how long before the fill's deadline the meter filled.

Stars use the game's rule. Clone Hero counts stars on your score without the solo bonus (src/core/stars.h). The on-screen score includes the bonus once a solo ends, so the counter reads a separate running total the replay already keeps. Drag past the solo at 3:10 in this mock: the score jumps by 6,400 but the star gap doesn't move. The cutoffs come from star_cutoffs, the same numbers the Stars tab shows.

Stars are drawn as shapes. The overlay's font, Courier Prime, has no ★ character, so the app would draw each star with the draw list, as it already does for the SP end triangles. I found no source on how the game colours stars 6 and 7, so the mock keeps all seven one gold.
