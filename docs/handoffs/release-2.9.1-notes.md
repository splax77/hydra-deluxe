Hydra Deluxe 2.9.1 fixes two things. The Paths tab now says when `Hide backend rows beyond` hides backend rows, and a MIDI chart loads under either drum track name Clone Hero accepts.

**Your saved results carry over.** Nothing reads `Stale` after the update. A `.mid` chart that was saved as `Can't analyze` because of its drum track's name stays that way until you click it, which analyzes it again, or until its file changes.

**The backend table says what it hides.** With `Hide backend rows beyond` checked, the `Backend timings` line used to count only the rows still shown. When every row was hidden, it read `0 notes near the SP end` and the table said `None.`, as if the activation had no notes near its SP end. Now the line counts every note and adds how many are hidden on each side of the SP end, like `8 notes near the SP end · 8 hidden: 4 before, 4 after`. When every row is hidden, the fold says so in place of `None.`, with the limit: `All 8 hidden: 4 before the SP end and 4 after, beyond 50 ms.` When only some are hidden, the same line shows under the table. `None.` now shows only when the activation really has no notes near its SP end.

**MIDI drum tracks load under either name.** Clone Hero plays a `.mid` chart whose drum track is named `PART DRUMS` or `PART DRUM`, in any mix of upper and lower case. Hydra Deluxe used to read only the exact name `PART DRUMS`, so a chart with a track named `PART DRUM` or `Part Drums` played in the game but read `Can't analyze`, with a reason like `No Expert Pro Drums notes in this chart.` Hydra Deluxe now reads both names in any case. When a chart has more than one track with either name, the first one in the file is the drum track, as in the game.
